Repositório dedicado aos meus estudos de Python, com exercícios e treinos

Criei este repositório para resolver os exercícios do livro **Introdução à Programação com Python — Algoritmos e Lógica de Programação para Iniciantes**, praticar os conceitos apresentados e desenvolver lógica de programação.

Também utilizo pra treinar conceitos que tenho pouco dominio antes de aplicar em outros projetos individuais.

- Estruturas de repetição
- Listas, dicionários, tuplas e conjuntos
- Strings
- Funções
- Manipulação de arquivos
- Classes e objetos
- Banco de dados
- Padrões de programação
- Interface gráfica

## Tecnologias utilizadas
